Search the ideas bank and return only matching entries.

The search query is: $ARGUMENTS

## What to do

1. Read `store.md` and `glossary.md`.
2. Parse the query: keyword, date, topic, or combination.
3. Search across all fields: idea number, time, day heading, raw thought, seed angle.
4. Return only matching entries in their original format, grouped under their original day headings.
5. If no matches: "no ideas matched '[query]'. try a different keyword or date, or type `/thought` to see everything."
6. After results: "found [N] idea(s). type `/post <number>` to draft any of these."
